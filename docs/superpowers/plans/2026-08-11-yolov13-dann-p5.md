# YOLOv13 P5 DANN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add P5-based DANN training to YOLOv13 with one mixed-domain forward, source-only detection loss, E0/E0.5/E1 controls, and unchanged prediction/export contracts.

**Architecture:** A `DANNDetectionModel` subclass performs a training-only layer traversal that returns normal Detect predictions plus layer-31 P5. A `DANNDetectionTrainer` pairs the ordinary source detection loader with a cycling target loader and injects target images into the model loss without copying the Ultralytics training loop. Normal `forward()` remains inherited and never calls the domain branch.

**Tech Stack:** Python 3.11, PyTorch, Ultralytics 8.3.63, PyYAML, pytest, optional ONNX/onnxruntime.

## Global Constraints

- Keep `cfg/models/v13/yolov13.yaml`, `Detect`, `v8DetectionLoss`, Backbone, Neck, P3/P4/P5 main paths, class count, predictor, and exporter unchanged.
- Capture layer 31 only; Detect remains layer 32 with inputs `[23, 27, 31]`.
- Source and target images execute one combined model traversal in E0.5 and E1.
- Detection loss receives source predictions and source annotations only.
- Do not add a dependency.
- Standard inference accepts one image input and exposes no domain output.
- Work on branch `feature/yolov13-dann-p5`.

```python
class GradientReversalFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, inputs, coefficient):
        ctx.coefficient = float(coefficient)
        return inputs.view_as(inputs)

    @staticmethod
    def backward(ctx, gradient):
        return -ctx.coefficient * gradient, None

class DomainClassifier(nn.Module):
    def __init__(self, in_channels, hidden_channels=256, dropout=0.1):
        super().__init__()
        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d(1), nn.Flatten(),
            nn.Linear(in_channels, hidden_channels), nn.ReLU(inplace=True),
            nn.Dropout(dropout), nn.Linear(hidden_channels, 2),
        )

    def forward(self, features):
        return self.classifier(features)
```

- [ ] **Step 3: Implement `DANNDetectionModel`**

Subclass `DetectionModel`. After `super().__init__`, validate `p5_layer == 31`, derive P5 channels from `self.model[-1].cv2[-1][0].conv.in_channels`, and construct `DomainClassifier`.

Implement `forward_with_p5` with the same saved-output routing as `_predict_once`:

```python
y, p5 = [], None
for module in self.model:
    if module.f != -1:
        images = y[module.f] if isinstance(module.f, int) else [images if j == -1 else y[j] for j in module.f]
    images = module(images)
    if module.i == self.p5_layer:
        p5 = images
    y.append(images if module.i in self.save else None)
return images, p5
```

In `loss`, fall back to `super().loss` without `target_img`. Otherwise validate both image tensors, concatenate them, call `forward_with_p5` once, slice every Detect feature at `Bs`, and call the unchanged criterion with the original source batch.

For E1, compute two-class domain CE over all P5 features after GRL, add `domain_loss_gain * domain_loss * Bs`, and append detached domain loss, accuracy, and lambda to the three detection items. For E0.5, skip the domain classifier and append three zeros.
